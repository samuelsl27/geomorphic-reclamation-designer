description=Geomorphic reclamation design for mined land: stable drainage networks with concave channel profiles, meanders, ridges, sub-ridges and swales, design TIN surface, contours and cut/fill balance, following the published fluvial-geomorphic (Natural Regrade / GeoFluv-type) method.

about=Open-source QGIS plugin that implements the fluvial-geomorphic landform design workflow for mine reclamation: project boundary, main channel and tributaries over valley-bottom polylines, target drainage density, concave longitudinal profiles, meander geometry after Williams (1986), ridges/sub-ridges/swales, TIN design surface, contours and cut/fill analysis. Every element is a QGIS layer, organised in groups and subgroups, and hydraulic properties travel as editable attributes so the user can edit any phase and regenerate the geometry. Developed by Samuel Saez Lopez with Emilio Trigueros (UPC / IMGA), same team as opengeorock.org. Not affiliated with, endorsed by or derived from Carlson Software; GeoFluv is a trademark of its owner and is cited only as the reference method.
